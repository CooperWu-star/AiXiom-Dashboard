# AiXiom-Dashboard

AiXiom Education Dashboard is a lightweight, single-page education experience showcasing learning pathways,
lesson previews, practice prompts, and progress tracking inspired by AiXiom education.

## Where is the app?

The app is the static single-page file at the repo root:

- Entry point: `index.html`
- Behavior: `app.js`
- Styling: `styles.css`

## Run locally

Open `index.html` directly in a browser or run a local server:

```bash
npm run dev
```

Or:

```bash
npm start
```

Or with Python:

```bash
python -m http.server 5173
```

Then visit `http://localhost:5173`.
